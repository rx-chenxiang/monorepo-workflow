# Apifox MCP 与接口章节编写说明

## 何时必须使用

填写技术设计文档 **§2.2.1** 下 **「##### 涉及到修改的接口 从通过MCP工具 apifox获取接口信息」** 对应的五列表格前：若 Cursor 已启用 **Apifox** 相关 MCP，**优先**用 MCP 查询、对齐接口定义。

## 建议操作顺序

1. 确认用户或 README 中 Apifox 项目 / 环境标识（如有）。  
2. 使用当前工作区可用的 Apifox MCP 工具（工具名以实际 MCP 为准）检索本需求接口，获取 Method、Path、参数、响应要点。  
3. 将结果填入表格，并可注明：「接口定义以 Apifox 项目《xxx》环境《yyy》为准，同步日期：YYYY-MM-DD。」

## MCP 不可用时的处理

在表格下方或「待确认事项」中写明接口依据（后端文档 / Swagger / 代码中的 api 定义），勿臆造 Path 与字段。

## 与项目代码一致

表格中的 Path、字段名须与仓库内 `api`、`request` 封装一致；若 Apifox 与代码不一致，**在文档中标注差异**。
