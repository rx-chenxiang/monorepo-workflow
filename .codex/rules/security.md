# 安全准则

## 强制安全检查

每次提交前必须确认：
- [ ] 无硬编码密钥（API Key、密码、Token）
- [ ] 所有用户输入已校验
- [ ] SQL 注入防护（使用参数化查询）
- [ ] XSS 防护（HTML 已消毒处理）
- [ ] CSRF 保护已启用
- [ ] 认证/授权已验证
- [ ] 所有端点已配置速率限制
- [ ] 错误信息不泄露敏感数据

## 密钥管理

- 绝对不要在源代码中硬编码密钥
- 始终使用环境变量或密钥管理服务
- 在应用启动时校验必需密钥是否存在
- 任何可能已泄露的密钥必须立即轮换

## 安全事件响应流程

发现安全问题时：
1. 立即停止当前工作
2. 使用 **security-reviewer** Agent 进行分析
3. 优先修复 CRITICAL 级别问题
4. 轮换所有可能已泄露的密钥
5. 排查整个代码库是否存在类似问题
